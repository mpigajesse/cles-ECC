# Clés ECC

Gestion des clés de cryptographie elliptique (ECC) pour les projets de cybersécurité.

## Structure

- `/keys` - Stockage des clés ECC
- `/docs` - Documentation
- `/scripts` - Scripts d'utilisation et de gestion

## Installation

```bash
git clone git@github.com:mpigajesse/cles-ECC.git
cd cles-ECC
```

## Utilisation

Instructions d'utilisation seront documentées ici.

## Sécurité

⚠️ **Important** : Les clés privées ne doivent JAMAIS être committées dans ce repository.
Utiliser des fichiers `.env` ou des secrets managers pour les secrets sensibles.
